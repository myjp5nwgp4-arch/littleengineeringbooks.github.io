Arduino Code

This sketch reads A0 at 12 bits, keeps only the top 3 bits to simulate a 3-bit ADC, and draws those three bits as digits on the built-in LED matrix. The bottom row shows a single moving LED marker for the position within the current band. Use the Copy button, paste it into the Arduino IDE and upload.

#include "Arduino_LED_Matrix.h"
// Hosted on https://LittleEngineeringBooks.com for educational purposes.

ArduinoLEDMatrix matrix;

const int ANALOG_PIN = A0;

uint8_t frame[96];

// 3x5 font for binary digits
const uint8_t DIGITS[2][5] =
{
  // 0
  {
    0b111,
    0b101,
    0b101,
    0b101,
    0b111
  },

  // 1
  {
    0b010,
    0b110,
    0b010,
    0b010,
    0b111
  }
};

void clearFrame()
{
  memset(frame, 0, sizeof(frame));
}

void setPixel(int x, int y, bool state = true)
{
  if (x < 0 || x > 11 || y < 0 || y > 7)
    return;

  frame[y * 12 + x] = state ? 1 : 0;
}

void drawBinaryDigit(uint8_t value, int xOffset)
{
  for (int y = 0; y < 5; y++)
  {
    for (int x = 0; x < 3; x++)
    {
      if (DIGITS[value][y] & (1 << (2 - x)))
      {
        setPixel(xOffset + x, y);
      }
    }
  }
}

void render()
{
  matrix.loadPixels(frame, 96);
}

void drawDisplay(uint8_t code, uint16_t remainder)
{
  clearFrame();

  // Draw three bits
  drawBinaryDigit((code >> 2) & 1, 0);   // MSB
  drawBinaryDigit((code >> 1) & 1, 4);   // Middle bit
  drawBinaryDigit(code & 1, 8);          // LSB

  // Marker along bottom row
  int markerX = map(remainder, 0, 511, 0, 11);

  setPixel(markerX, 7);

  render();
}

void setup()
{
  matrix.begin();

  analogReadResolution(12);

  Serial.begin(115200);

  Serial.println("3-bit ADC Quantisation Demo");
}

void loop()
{
  // Full-resolution reading
  uint16_t adc = analogRead(ANALOG_PIN);

  // Simulated 3-bit ADC
  uint8_t code = adc >> 9;

  // Position within current quantisation bucket
  uint16_t remainder = adc & 0x01FF;

  drawDisplay(code, remainder);

  Serial.print("ADC=");
  Serial.print(adc);

  Serial.print("  Binary=");
  Serial.print((code >> 2) & 1);
  Serial.print((code >> 1) & 1);
  Serial.print(code & 1);

  Serial.print("  Bucket=");
  Serial.println(remainder);

  delay(20);
}

What we're doing

The potentiometer makes a voltage divider whose output, between 0 V and 5 V, is read on A0. The ADC is run at 12 bits (0 to 4095), but the sketch only keeps the top 3 bits (adc >> 9), as if the converter only had 3 bits. That splits the input range into 23 = 8 equal bands, each 512 counts (about 0.625 V) wide.

The LED matrix shows two things at once:

  • The three digits are the 3-bit output code, from 000 to 111.
  • The single LED on the bottom row shows where you are inside the current band. It is the 9 bits that were thrown away (adc & 0x01FF), scaled across the 12 columns.

Why this matters

Quantisation is the step where a continuous voltage is forced onto a limited set of values. Turn the pot slowly and the marker crawls from left to right while the digits stay perfectly still. Only when the marker runs off the right-hand end, and the voltage overflows the top of the band, do the digits change by one step and the marker jump back to the left.

Every voltage inside a band gives exactly the same code, so the converter cannot tell them apart. That lost detail is the quantisation error, and it can be as large as one whole band. More bits means narrower bands and a smaller error, which is why a 12-bit ADC resolves much finer detail than a 3-bit one.

Testing and results

Photos of the LED matrix for five pot settings. Watch the digits and the marker position:

000, bottom of the band: the ADC reading is near 0, so the bucket position is at its minimum and the marker sits at the left.

001, top of the band: the voltage is about to tip into the next band. The marker is at the far right, but the digits still read 001.

010, bottom of the band: the voltage has just crossed the threshold. The code stepped from 001 to 010 and the marker jumped back to the left.

101, middle of the band: the marker sits half way along. Many different voltages in this band all give the same code, 101.

111, top of the range: the highest code, with the marker at the far right as the input approaches full scale.

Notice that going from 001 at the top of its band to 010 at the bottom of the next one takes only a tiny change in voltage, while moving the marker across a whole band changes nothing in the digits.
