1 Voltage Follower (Buffer)

Gain of 1. Passes Vin to Vout while isolating the source from the load.

Vout = Vin

Schematic

Code

// Reads Vout on A0 and compares it with the expected value
const float VREF = 5.0;      // ADC reference (V)
const float VIN  = 1.0;      // test input voltage (V)

void setup() { Serial.begin(9600); }
void loop() {
  float vout = analogRead(A0) * VREF / 1023.0;
  float expected = VIN;
  Serial.print("Measured: "); Serial.print(vout, 3);
  Serial.print(" V  Expected: "); Serial.println(expected, 3);
  delay(500);
}

2 Non-Inverting Amplifier

Amplifies the input without flipping its sign.

Vout = Vin × (1 + Rf/Rg)

Schematic

Code

// Reads Vout on A0 and compares it with the expected value
const float VREF = 5.0;      // ADC reference (V)
const float VIN  = 1.0;      // test input voltage (V)
const float RF = 10000, RG = 1000;
void setup() { Serial.begin(9600); }
void loop() {
  float vout = analogRead(A0) * VREF / 1023.0;
  float expected = VIN * (1.0 + RF / RG);
  Serial.print("Measured: "); Serial.print(vout, 3);
  Serial.print(" V  Expected: "); Serial.println(expected, 3);
  delay(500);
}

4 Summing Amplifier (Adder)

Adds several inputs together, each with its own weighting.

Vout = −Rf × (V1/R1 + V2/R2)

Schematic

Code

// Reads Vout on A0 and compares it with the expected value
const float VREF = 5.0;      // ADC reference (V)
const float VIN  = 1.0;      // test input voltage (V)
const float RF = 10000, R1 = 10000, R2 = 10000;
const float V1 = 1.0, V2 = 0.5;
void setup() { Serial.begin(9600); }
void loop() {
  float vout = analogRead(A0) * VREF / 1023.0;
  float expected = -RF * (V1 / R1 + V2 / R2);
  Serial.print("Measured: "); Serial.print(vout, 3);
  Serial.print(" V  Expected: "); Serial.println(expected, 3);
  delay(500);
}

5 Differential Amplifier

Amplifies the difference between two inputs and rejects what they share.

Vout = (V2 − V1) × (Rf/R1)

Schematic

Code

// Reads Vout on A0 and compares it with the expected value
const float VREF = 5.0;      // ADC reference (V)
const float VIN  = 1.0;      // test input voltage (V)
const float RF = 10000, R1 = 10000;
const float V1 = 1.0, V2 = 1.5;
void setup() { Serial.begin(9600); }
void loop() {
  float vout = analogRead(A0) * VREF / 1023.0;
  float expected = (V2 - V1) * (RF / R1);
  Serial.print("Measured: "); Serial.print(vout, 3);
  Serial.print(" V  Expected: "); Serial.println(expected, 3);
  delay(500);
}

6 Comparator

Compares two voltages and swings the output fully high or low. A standard op-amp (the same MCP6021) stands in for a dedicated comparator chip: it isn’t ideal, since it is slower to recover from saturation and has no built-in hysteresis, but it works.

Vout = high if V+ > V−, otherwise low

Schematic

Code

// Reads the comparator output on D2 and reports its state
const int OUT_PIN = 2;
void setup() { Serial.begin(9600); pinMode(OUT_PIN, INPUT); }
void loop() {
  Serial.println(digitalRead(OUT_PIN) ? "Input ABOVE reference" : "Input BELOW reference");
  delay(500);
}

7 Schmitt Trigger

A comparator with hysteresis, so noisy inputs don't cause chattering.

Thresholds: Vth = Vout × R1/(R1+R2)

Schematic

Code

// Counts output transitions to show noise rejection
const int OUT_PIN = 2;
int last = LOW; unsigned long edges = 0;
void setup() { Serial.begin(9600); pinMode(OUT_PIN, INPUT); }
void loop() {
  int now = digitalRead(OUT_PIN);
  if (now != last) { edges++; last = now; Serial.println(edges); }
}

9 Integrator

Output is the running total (integral) of the input over time.

Vout = −(1/RC) ∫ Vin dt

Schematic

Code

// Integrates a constant input in software to compare with the measured Vout
const float VREF = 5.0, VIN = 0.1, R = 10000, C = 100e-9;
unsigned long t0;
void setup() { Serial.begin(9600); t0 = millis(); }
void loop() {
  float t = (millis() - t0) / 1000.0;
  float vout = analogRead(A0) * VREF / 1023.0;
  Serial.print("Measured: "); Serial.print(vout, 3);
  Serial.print(" V  Expected: "); Serial.println(-VIN * t / (R * C), 3);
  delay(100);
}

10 Differentiator

Output is proportional to how fast the input changes.

Vout = −RC × dVin/dt

Schematic

Code

// Estimates the input slope and prints the expected Vout
const float R = 10000, C = 100e-9;
float prevV = 0; unsigned long prevT = 0;
void setup() { Serial.begin(9600); }
void loop() {
  unsigned long t = micros();
  float v = analogRead(A1) * 5.0 / 1023.0;   // Vin on A1
  float dt = (t - prevT) / 1e6;
  if (prevT) Serial.println(-R * C * (v - prevV) / dt, 3);
  prevV = v; prevT = t; delay(10);
}

11 Active Low-Pass Filter

Passes low frequencies and attenuates high ones, with optional gain.

fc = 1/(2πRfCf), gain = −Rf/Rin

Schematic

Code

// Calculates cutoff frequency and gain for the chosen parts
const float RF = 10000, RIN = 10000, CF = 10e-9;
void setup() {
  Serial.begin(9600);
  Serial.print("Cutoff (Hz): "); Serial.println(1.0 / (2 * PI * RF * CF));
  Serial.print("Gain: "); Serial.println(-RF / RIN);
}
void loop() {}
